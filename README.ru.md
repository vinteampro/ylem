# Ylem: The First 400,000 Years

*Первые 400 000 лет — медитация на научной основе.*

[English](README.md) · **Русский**

Медитативная игра о рождении вещества. Ты управляешь молодой Вселенной — темпом
расширения и плотностью вещества — и смотришь, как кварки собираются в протоны,
протоны и нейтроны — в гелий, а ядра ловят электроны и становятся первыми атомами.

Прототип: ~5 минут, от первой микросекунды до тёмных веков.

## Как запустить

Открой папку в [Godot 4.7](https://godotengine.org/download/): Import → выбери `project.godot`,
затем запусти игру клавишей **F5**. Как собрать exe, Linux- и веб-версию — в разделе «Сборка».

## Управление

**Рычаги**

| | |
|---|---|
| **Темп расширения** | медленнее — нейтроны успевают распасться, гелия меньше; быстрее — больше; меньше нуля — сжатие и разогрев. Видно сразу: поток частиц от центра, яркость, тон звука |
| **Плотность вещества** | плотнее — частиц больше, дейтерий сгорает почти весь; разреженнее — частиц меньше, дейтерия остаётся много |
| **Ход времени** | от паузы до ×2 |
| **Отпустить** | рычаги сами плавно вернутся к параметрам нашей Вселенной |
| Около значения нашей Вселенной | ползунок «прилипает» к нему с тихим откликом |
| Двойной клик по ползунку | вернуть значение нашей Вселенной |
| Колесо над ползунком | шаг; с Shift — мелкий шаг |

Темп расширения слышно и видно: пока тянешь ползунок, звучит линия H-альфа и скользит вниз
при ускорении (красное смещение) и вверх при замедлении (синее), а кадр на время уходит
в красный или синий. Музыка постоянно чуть смещена по высоте. Плотность меняет «тесноту»
звука: плотнее — глуше и суше, разреженнее — с длинным эхом.

Пока идёт нуклеосинтез, в составе вещества виден **прогноз** («24,9% → 31,2%», ромбик на шкале)
и засечка — значение в нашей Вселенной. Кольцо вокруг строки нейтронов — часы их распада.

**Рука и камера**

| | |
|---|---|
| ЛКМ (держать) | сжать и закрутить плазму: реакции идут у тебя под рукой |
| ПКМ (держать) | разредить |
| Клик по частице | следить за ней и читать её историю (Esc — отпустить) |
| Колесо мыши | приблизить / отдалить |
| Средняя кнопка, стрелки, WASD | сдвинуть камеру |
| Пробел | пауза |
| H | скрыть интерфейс |
| F / F11 | полный экран |
| English / Русский | кнопка языка в панели рычагов (по умолчанию — язык системы) |

Касания — это **флуктуации плотности**. Где ты сжимал плазму, после рекомбинации проступят
холодные пятна на реликтовом излучении (эффект Сакса — Вольфа), а в тёмных веках
гравитация стянет туда вещество — будущие места первых звёзд. Это игровая вольность:
число реакций считает модель, а рука только решает, где показать вспышку (см. «Упрощено»).

В конце игра сравнивает получившийся состав с нашей Вселенной.

Игра начинается со слабой точки света в темноте. Часто кликай по ней, чтобы разбудить её
и запустить Большой взрыв (или нажми Enter).

### Проверка против AlterBBN

`tools/sim_check.gd` прогоняет модель на сетке η (от ×0,1 до ×10) и числа нейтрино
(ΔN от −2 до +6) и сравнивает с открытым кодом [AlterBBN 2.2](https://alterbbn.hepforge.org/)
(Arbey et al., CPC 183 (2012) 1822), собранным с теми же η, N_ν = 3,044 и τ_n = 878,4 с.
Допуски: Yp ±0,0025, D/H и ³He/H ±6%, ⁷Li/H ±12%. Все 10 точек сетки в допусках:

| η×, ΔN | Yp, модель / AlterBBN | D/H | ³He/H | ⁷Li/H |
|---|---|---|---|---|
| 0,1, 0 | 0,2054 / 0,2065 | 9,81 / 9,84 ×10⁻⁴ | 5,43 / 5,41 ×10⁻⁵ | 1,24 / 1,24 ×10⁻⁹ |
| 1, 0 | 0,2457 / 0,2469 | 2,44 / 2,42 ×10⁻⁵ | 1,03 / 1,03 ×10⁻⁵ | 5,40 / 5,50 ×10⁻¹⁰ |
| 10, 0 | 0,2658 / 0,2670 | 6,34 / 6,13 ×10⁻⁹ | 3,88 / 3,89 ×10⁻⁶ | 6,67 / 6,72 ×10⁻⁹ |
| 1, +3 | 0,2790 / 0,2802 | 3,42 / 3,41 ×10⁻⁵ | 1,16 / 1,16 ×10⁻⁵ | 4,15 / 4,20 ×10⁻¹⁰ |

Там же проверяется, что прогноз в игре (крупный шаг 0,05) отличается от точного счёта
меньше чем на 0,001 по Yp и 3% по D/H.

### Что получается при параметрах нашей Вселенной

| | Модель | Реальность |
|---|---|---|
| Гелий-4, доля массы | 24,57% | AlterBBN 24,69%, PRIMAT 24,71%; наблюдения 24,5 ± 0,3% (PDG 2024) |
| D/H | 2,44×10⁻⁵ | AlterBBN 2,42×10⁻⁵; наблюдения (2,547 ± 0,029)×10⁻⁵ (PDG 2024) |
| ³He/H | 1,03×10⁻⁵ | AlterBBN 1,03×10⁻⁵ |
| ⁷Li/H | 5,4×10⁻¹⁰ | AlterBBN 5,5×10⁻¹⁰; в старых звёздах 1,6×10⁻¹⁰ — «литиевая проблема» |
| T_ν/T после аннигиляции e± | 0,7148 | (4/11)^⅓ = 0,7138 |
| Адронизация | ~20 мкс | ~10–20 мкс |
| Синтез гелия (половина итога) | ~4 мин | 3–4 мин |
| Половина водорода нейтральна | z ≈ 1270 | z ≈ 1270 |
| Поверхность последнего рассеяния (пик функции видимости) | z* ≈ 1096, ~368 тыс. лет | Planck 2018: z* = 1089,8 |
| Остаточная ионизация | 3×10⁻⁴ | ~2–3×10⁻⁴ |

**Почему гелия 24,57%, а не 24,7%.** Гелий почти целиком задаётся отношением нейтронов к
протонам в момент, когда «замерзают» слабые реакции. У нас эти реакции посчитаны в
борновском приближении с кулоновской поправкой и нормированы на время жизни нейтрона.
Точные коды добавляют ещё радиационные поправки, поправки на конечную массу нуклона и
на нагрев нейтрино при аннигиляции e±. Отсюда сдвиг −0,0012, одинаковый на всей сетке.
Наблюдения (24,5 ± 0,3%) согласны и с моделью, и с точными кодами.

**Почему z* = 1096, а не 1090.** Водород рекомбинирует по трёхуровневому атому Пиблса без
поправок RECFAST/HyRec, гелий — по Саха. Это даёт рекомбинацию чуть раньше, примерно на 0,5%
по красному смещению.

**Как устроено:**
- *Расширение* — уравнение Фридмана: H² = 8πG/3·ρ, где ρ — фотоны, e± и мюоны (точные
  интегралы Ферми — Дирака), кварки и адроны, нейтрино (N_eff = 3,044), вещество и Λ.
  Температура следует из сохранения энтропии, поэтому при аннигиляции e± фотоны
  подогреваются, а отщепившиеся нейтрино нет.
- *Слабые реакции n ⇄ p* — интегралы по спектрам e±, ν и ν̄ при своих температурах
  (6 процессов, включая распад), с функцией Ферми.
- *Ядра* — 8 видов (n, p, D, T, ³He, ⁴He, ⁷Li, ⁷Be), 18 реакций, обратные — по детальному
  равновесию. Система жёсткая, поэтому шаг неявный: двухстадийная схема SDIRK2 второго порядка
  с методом Ньютона. Выше 27 млрд К ядра не живут, считаются только n ⇄ p.
- *Рекомбинация* — водород по Пиблсу (через уровень n = 2), гелий по Саха. Момент
  прозрачности — пик функции видимости g = τ'·e^(−τ).
- *Тёмные века* — контраст сгущений растёт как масштабный фактор (δ ∝ a).

**Упрощено:**
- кварк-адронный переход — плавная склейка пионного газа и кварк-глюонной плазмы, а
  адронизация — феноменологическая кривая (на нуклеосинтез не влияет);
- нейтрино отщепляются мгновенно при 2 МэВ, неполное отщепление учтено только через N_eff;
- слабые реакции без радиационных поправок (Yp на 0,001 ниже точных кодов, см. выше);
- нет ⁶Li и ядер тяжелее ⁷Be: на итоговый состав они не влияют;
- рычаг «темп расширения» умножает H во все эпохи сразу. Прямого эталона у него нет; ближайший
  аналог — лишние сорта нейтрино, и он проверен против AlterBBN;
- «рука» игрока — игровая вольность. Реальные флуктуации заложены инфляцией задолго до первой
  микросекунды. Число реакций считает модель, рука только решает, где показать вспышку.
  Знак пятен — как у эффекта Сакса — Вольфа на больших масштабах (сгущение выглядит
  холодным); на масштабах меньше звукового горизонта он зависел бы от фазы акустических
  колебаний. Неоднородности реликтового излучения усилены примерно в 10 000 раз, иначе их не видно;
- цвета кварков условные.

## Устройство проекта

```
scenes/main.tscn            — единственная сцена; всё остальное собирается в коде
scripts/universe.gd         — физическая модель (только числа, без графики)
scripts/particle_field.gd   — частицы, слияния, вспышки, гамма-кванты (MultiMesh + HDR)

scripts/hud.gd              — интерфейс: шкала времени, состав, рычаги, итоги
scripts/audio_director.gd   — эмбиент, «колокольчики» реакций, музыка по эпохам
scripts/i18n.gd             — все тексты на русском и английском (интерфейс, эпохи, реплики, кодекс)
scripts/palette.gd          — цвета плазмы по излучению чёрного тела
shaders/plasma.gdshader     — фон: плазма и реликтовое излучение
shaders/haze.gdshader       — дымка поверх частиц
audio/music/                — музыка по эпохам (Suno, по треку на эпоху)
tools/sim_check.gd          — проверка физики без графики (против AlterBBN 2.2)
```

## Сборка

Нужен [Godot 4.7](https://godotengine.org/download/) и шаблоны экспорта той же версии
(в редакторе: Editor → Manage Export Templates). Сборки кладутся в папку `build/`
внутри проекта (она не попадает в git):

```
godot --headless --path . --export-release "Windows Desktop" build/Ylem.exe
godot --headless --path . --export-release "Linux" build/linux/Ylem.x86_64
godot --headless --path . --export-release "Web" build/web/index.html
```

или в редакторе: Project → Export. Веб-сборка — без потоков, поэтому на itch.io
не нужна галочка SharedArrayBuffer. В браузере (WebGL) кадр не хранит яркость
выше 1, и `main.gd` там приглушает частицы и фон, а в конце кадра поднимает
яркость обратно (`WEB_GAIN`) — иначе пропадает свечение.

## Для разработки

Проверить физику при разных параметрах:

```
godot --headless --path . --script res://tools/sim_check.gd
```

Начать сразу с нужной температуры и сделать скриншоты:

```
godot --path . -- --start-T=1.5e9 --shot=shot_%d.png --shot-at=5,20
```

Ещё отладочные аргументы: `--expansion=2 --density=0.3` (стартовые рычаги),
`--demo=touch` (виртуальная рука рисует круг), `--demo=follow` (выбрать частицу),
`--launch-at=2` (разбудить точку на стартовом экране самому на 2-й секунде).
С `--start-T` стартовый экран пропускается.
